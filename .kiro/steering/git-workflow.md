# Git Workflow

## Regras de Commit

- Faça commit automaticamente após cada alteração concluída, sem perguntar ao usuário
- Use mensagens de commit descritivas em português
- Faça push automaticamente após o commit, sem perguntar

## Padrão de Mensagens

- Prefira mensagens curtas e diretas
- Descreva O QUE foi feito, não COMO
